# 所得税（給与所得だけの居住者の年税額）

[制度の規則の入口](README.md)／規則: `jp-income-tax-salary-2025`・`jp-income-tax-salary-2026`（版`1`、状態`draft`）／制度データ: `rules/income-tax/jp-2025.json`・`rules/income-tax/jp-2026.json`／使う担当: T16（所得税の試算）、T22（確定申告の準備）

給与の収入だけがある居住者の、令和7年分（2025年）・令和8年分（2026年）の所得税の年税額を、年末調整と確定申告の手続ごとに求める規則。値と原典の箇所は制度データが正本で、この資料は範囲・選び方・順序・丸め・未確認の事項を書く（値を書き写さない）。

## 範囲

| 項目 | この規則で扱う | 扱わない（未対応・入力） |
| --- | --- | --- |
| 対象者 | 居住者で、その年12月31日まで生存し、年の中途で出国しない人 | 非居住者（基礎控除の加算や扶養親族の要件が違う）。年の中途で死亡・出国した人（家族の判定の時点が死亡・出国の時になる。下の「年齢と家族の判定」） |
| 所得 | 給与所得だけ | 事業・不動産・公的年金等・退職・分離課税等。給与所得と公的年金等の双方がある場合の所得金額調整控除 |
| 年分 | 令和7年分・令和8年分 | ほかの年分 |
| 手続（`procedure`） | `year-end-adjustment`（年末調整）、`tax-return`（確定申告） | 準確定申告（死亡・出国）、`withholding`（給与の支払ごとの源泉徴収。源泉徴収税額表の月額表・日額表・賞与の算出率の表は行を写して確かめていない） |
| 給与所得 | 給与所得控除後の給与等の金額（年末調整等のための表と式）、子ども・特別障害者等を有する者等の所得金額調整控除 | 特定支出控除 |
| 所得控除 | 基礎控除、配偶者控除・配偶者特別控除、扶養控除、特定親族特別控除の額（家族の適用要件は、事前に確かめた入力。下の「年齢と家族の判定」） | 社会保険料控除・小規模企業共済等掛金控除の額（入力。明細・申告書から求めるのはT16）、生命保険料・地震保険料・障害者・寡婦・ひとり親・勤労学生等の控除（入力の合計`otherIncomeDeductions`。額の表は制度データにあるが、該当の要件は範囲外）、医療費・寄附金・雑損控除（確定申告だけの入力の合計`returnOnlyDeductions`。年末調整では控除しない） |
| 税額控除 | なし | 住宅借入金等特別控除、配当控除、外国税額控除等（入力に当てはまるものがあれば`unsupported`） |
| 復興特別所得税 | 令和7年分・令和8年分の2.1% | 令和9年以後の税率の引下げと防衛特別所得税 |
| 予定納税 | なし（申告納税額まで） | 第3期分の税額（予定納税額を引いた額） |
| 家族 | 12月31日に生存している、居住者である配偶者・親族 | 年の中途で死亡した配偶者・親族（判定の時点を確かめていない）、非居住者である配偶者・親族 |

範囲外に当たる入力は、manifestの規則の`unsupportedInputs`に書く。当たる入力の計算runは`unsupported`（`target`が規則の適用の範囲に当たっても）。値が分からない（`unknown`）入力は未対応ではなく不足の入力で、runは`incomplete`。

## 規則の選び方

改正（令和7年度・令和8年度の税制改正の基礎控除の見直し・引上げ等）は、各年の12月1日に施行され、その年分以後の所得税に適用される。年末調整は「給与の支払者がその年最後に給与の支払をする際」に行うので、施行日より前に行う年末調整と、施行日より前に提出する準確定申告には、改正前の規則が適用される（令和8年度改正Q&AのQ1-1・Q1-3・Q6-1、令和7年度改正の案内）。そのため`referencePoint`で規則を選ぶ（[README](README.md)の「規則の選び方」）。

| `target.year` | `procedure` | `referencePoint`（`date`） | 規則 |
| --- | --- | --- | --- |
| 2025（暦年） | `year-end-adjustment`（年末調整を行う日） | 2025-12-01以後 | `jp-income-tax-salary-2025` |
| 2025 | `tax-return`（申告書を提出する日。提出前の試算では予定日） | 2025-12-01以後 | `jp-income-tax-salary-2025` |
| 2026 | `year-end-adjustment` | 2026-12-01以後 | `jp-income-tax-salary-2026` |
| 2026 | `tax-return` | 2026-12-01以後 | `jp-income-tax-salary-2026` |
| 2025・2026 | `year-end-adjustment`・`tax-return` | 各年の12月1日より前 | 未対応（改正前の規則は確かめていない）→`unsupported` |
| どの年も | `withholding` | — | 未対応 → `unsupported` |
| ほかの年 | — | — | 未対応 → `unsupported` |

`target.jurisdiction`は`{ kind: national, code: JP }`。`target.scope`は計算器（T16）が決める（年末調整は1つの支払者、確定申告は全支払者が基本）。

令和8年分の確定申告の端数処理は、取得日に令和8年分の確定申告の手引きが未公表なので、同じ法令（国税通則法第119条）による令和7年分の手引きで確かめた（制度データの`rounding`の`location`に記載）。令和8年分の手引きの公表後に確かめ直す（下の「未確認の事項」）。

## 入力

計算器（T16）が入力の要求として持つ値。分からない値は`unknown`のままにし、0で補わない（不足の入力として`incomplete`）。手続ごとの必須の入力とその型（`type`: 金額は0以上の整数、真偽値、列挙）はmanifestの規則の`requiredInputs`が正本で（`when`で条件付き: 所得金額調整控除の対象かは給与等の収入金額が850万円を超えるときだけ）、欠けた・`null`（`nullable`でないもの）・`unknown`の必須の入力があれば、runを`computed`・`provisional`にしない。家族がないこと（`spouse`が`null`、`relatives`が空の並び）は欠けた入力ではない。家族の入力の型と許す値は、生年月日が日付、合計所得金額が0以上の整数、生存・居住者と真偽の適用要件が真偽値、関係が制度データの`domain`の列挙で、どれも「unknown」（不足）を許す。ほかの値は既知の入力として扱わない（検査が拒否する）。家族の適用要件の入力（No.1177の(9)を含む）が必要かどうかは、下の「家族の控除の判定の手順」で控除ごとに決まる。

## 計算の順序

制度データの値を、次の順に使う。各段階の結果を結果の項目（`results`の`key`）として持つ。

1. **給与所得控除後の金額**（`employment-income`）: 給与等の収入金額が660万円未満なら、年末調整等のための給与所得控除後の給与等の金額の表の行の値（表引き。丸めではない）。表の行は、220万円（令和7年分は190万円）以上660万円未満では4,000円刻みで、行の最低金額（年調給与額）に式を当てた値（令和8年分は国税庁「電子計算機等による年末調整」に式が示されている。制度データの`rows-linear`）。660万円以上850万円未満は収入金額×90%−110万円（1円未満切捨て）、850万円以上は収入金額−195万円。令和8年分は、租税特別措置法第29条の4の特例（収入金額69万1,000円以上74万1,000円未満は給与所得なし、74万1,000円以上219万1,000円未満は収入金額−74万円、219万1,000円以上220万円未満は資料の表の固定の値）を反映した表による（区分の正本は制度データ。表は74万1,000円未満を0、74万1,000円から収入金額−74万円とする）。
2. **所得金額調整控除**（`income-adjustment-deduction`）: 収入金額が850万円を超え、対象に当たるとき、（収入金額（1,000万円超なら1,000万円）−850万円）×10%（1円未満切上げ）。当たらなければ0。1の値から引いたもの（給与所得控除後の給与等の金額（調整控除後））が給与所得の金額で、給与所得だけなので合計所得金額になる（年末調整のしかたの基礎控除額の表の、収入が給与だけの場合の収入金額は、所得金額調整控除の適用があれば異なると注記されている）。
3. **基礎控除**（`basic-deduction`）: 合計所得金額で表を引く。
4. **配偶者控除・配偶者特別控除**（`spouse-deduction`・`spouse-special-deduction`）、**扶養控除**（`dependent-deduction`）、**特定親族特別控除**（`specific-relative-deduction`）: 下の「年齢と家族の判定」による。
5. **課税される所得金額**（`taxable-income`）: 合計所得金額から、入力の控除と3・4の控除を引き、1,000円未満を切り捨てる（0未満なら0）。年末調整では「課税給与所得金額」。
6. **算出所得税額**（`computed-income-tax`）: 速算表（課税される所得金額×税率−控除額）。課税される所得金額が1,000円の倍数なので、端数は生じない。
7. 年末調整: **年調年税額**（`annual-tax`）＝算出所得税額×102.1%（100円未満切捨て）。**過不足額**（`year-end-balance`）＝毎月の徴収税額の合計−年調年税額（正は超過額＝還付、負は不足額＝徴収。給与明細の`yearEndAdjustment`と同じ符号）。
8. 確定申告: **復興特別所得税額**（`reconstruction-tax`）＝基準所得税額（算出所得税額）×2.1%（1円未満切捨て）。**所得税及び復興特別所得税の額**（`income-tax-total`）＝6＋復興特別所得税額。**申告納税額**（`filing-tax-balance`）＝所得税及び復興特別所得税の額−源泉徴収税額で、黒字なら100円未満切捨て、赤字（還付）はそのまま（符号で分かれる処理。丸めは黒字の場合だけ）。

### 年末調整の対象者

## 年齢と家族の判定

- **判定の時点（この版の範囲）:** その年の12月31日の現況（タックスアンサーNo.1180・1191・1177）。制度データの`ageDeterminationDate`。本人が年の中途で死亡・出国する場合は、その時の現況で判定する（同）が、この版では扱わない（上の「範囲」。`unsupportedInputs`）。例: 2026-12-10に死亡した人の準確定申告で、2008-12-20生まれの親族は死亡の時は18歳、12月31日なら19歳で、特定扶養親族かどうかが変わる（REG-21）。
- 年齢はその日の満年齢で、誕生日の前日に1つ加わる。このため、例えば令和8年分の特定扶養親族（19歳以上23歳未満）は平成16年1月2日〜平成20年1月1日生まれ（制度データの`bornFrom`・`bornTo`は資料の表の生年月日の範囲を写したもの。検査が年齢の範囲と一致することを確かめる）。特定親族特別控除の年齢（19歳以上23歳未満）も、制度データの`specificRelativeDeduction`の`ageMin`・`ageBelow`・`bornFrom`・`bornTo`で読める。
- 扶養親族・同一生計配偶者の合計所得金額の要件は、令和7年分58万円以下、令和8年分62万円以下。特定親族は58万円（令和8年分は62万円）超123万円以下。配偶者特別控除の配偶者は58万円（令和8年分は62万円）超133万円以下。
- 控除対象扶養親族は16歳以上。年齢16歳未満の扶養親族は扶養控除の対象にならない。控除対象扶養親族に当たる人には、特定親族特別控除を適用しない（No.1177の(6)。`excludedIfDependent`）。
- 配偶者控除・配偶者特別控除は、本人の合計所得金額が1,000万円を超えると適用されない。配偶者控除が適用される配偶者には、配偶者特別控除を適用しない。
- **適用要件（所得・年齢だけで控除しない）:** 各控除は、制度データの`eligibility`の条件がすべて満たされるときだけ適用する。1つの条件は1つの入力か、原典の例外を含む代替（`anyOf`。どれかを満たせばよい）。既知の代替で満たせば、ほかの代替が分からなくても条件は満たす（例: 配偶者が配偶者特別控除を適用していなければ、年中の源泉徴収が分からなくてもNo.1195の(4)(5)は満たす）。例: 事業専従者である親族は扶養控除・特定親族特別控除の対象にならない（No.1180の(4)、No.1177の(4)）。配偶者が配偶者特別控除を受けているときは、配偶者特別控除を受けられない（No.1195の(3)）。これらの入力は、利用者・勤務先の申告書で事前に確かめたものとして受け取り、計算器は推測しない。
- **家族の控除の判定の手順（PR29-R006）:** 人ごと・控除ごとに同じ手順で判定する。(1) 候補の判定: 合計所得金額・年齢（・配偶者の控除では本人の合計所得金額）がその控除の範囲に当たるか（当たらない・当たる・未決）。本人の合計所得金額は、所得金額調整控除の対象かが分かれば実際の控除額で求め（対象でなければ0、収入金額が850万円以下なら0）、分からないときだけ0と実際の額の範囲で判定する（範囲が1,000万円をまたげば未決。REG-44〜48と、検査の組合せの試験）。(2) 適用要件: 条件をすべて満たすか（AND。条件の中の代替はOR）。(3) 候補でない、または既知の不適格の条件が1つでもあれば、その控除は0で、その控除の未知の入力は不足に数えない（REG-37: 16歳未満の子だけならNo.1177の(9)も子の要件も要らない。REG-38: 事業専従者と分かれば所属が分からなくても扶養控除0）。(4) 候補か未決で、適用要件が決まらなければ、決まらない入力（と、候補を決める生年月日・合計所得金額、額を決める入力）だけを不足に数え、その控除と、それに続く課税される所得金額以降は`unknown`で、runは`incomplete`（REG-23・REG-39）。適用の余地がある未知の値を0で補わない。欠けた適用要件の入力は`unknown`と同じに扱う。納税者側の入力（No.1177の(9)）も、特定親族特別控除の適用要件として同じ手順で扱う。型の検査は、この手順と別に、値があれば常に行う。
- 非居住者である家族、年の中途で死亡した家族は範囲外（`unsupported`）。障害者・寡婦・ひとり親・勤労学生の要件は範囲外（控除の額は入力の合計）。
