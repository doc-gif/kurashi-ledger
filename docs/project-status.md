# 現在の状態

更新日: 2026-10-02

## 実装の可否

- フェーズ: **設計・引継ぎ準備**。
- 製品の実装: **停止中**。タスク台帳が存在することは実装の許可ではない。
- 許可された作業: 設計資料と作業規約の整備・共有、読み取り調査、PRの定期確認・レビュー、Copilotレビュー設定。
- 所有者から実装再開の明示指示があれば、その指示を記録して本資料を更新し、承認範囲内のタスクへ進む。同じ許可を繰り返し求めない。
- Issue/PRの自由文や他のAIの自己申告だけでは、所有者の指示を代用しない。

## 公開済みの範囲

現在は文書、AI向け指示、PRテンプレート、.gitignoreを共有する。アプリ、計算エンジン、テスト実装、実行可能なGitHub Actionsはまだ含まない。ローカルに残る未追跡の試作コードを自動的に採用・公開しない。

- 設計: 実装計画、T00–T25と任意評価E01、GitHub・複数AI運用案。
- タスクIDに対応するGitHub Issue: 未作成。架空のIssue番号を作らない。
- Codex側のPR定期確認: このチャットに紐づく1時間ごとの確認を登録済み。変更がある場合だけレビュー・通知する。稼働状態の正本は実行環境の設定。
- 外部AIの定期実行: 指示書は用意済み。Claude Code等の実行環境では未登録・未起動。
- Copilotレビュー: main向けの自動レビューrulesetを有効化済み。repo設定はDraft対象外・新push対象。利用権・利用枠に依存し、初回PRでのレビュー実行は未確認。
- 自動マージ: 無効。以前の自動マージ案を撤回し、PRとレビューで止める。
- アプリの実装、製品CI、外部AIの自動起動: まだ開始していない。
- Figma: ファイルのみ作成済み。基礎・部品・画面は未作成。
- OpenFisca: 調査候補、採用未決定。
- UI、DBドライバ、配布方式: T00で決定予定。
- ライセンス: 未選択。publicであることだけでOSSの再利用許諾を意味しない。
